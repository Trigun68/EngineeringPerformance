# Имена файлов экспорта

Дата обновления: 2026-08-22  
Реализация: `ExportFileNameBuilder`, `IExportFileNameService`, `client/src/utils/exportFileName.ts`

Все выгрузки Excel, PDF и CSV получают одно и то же русское имя. Источник правды — заголовок `Content-Disposition` на сервере; браузер и клиент его не переименовывают.

## Шаблон

```
{модуль}_{вкладка}[_{уточнение}]_-_{код}_{название}_({версия}).{ext}
```

Разделитель блоков — подчёркивание. Тире `_ - _` отделяет отчёт от шифра и названия проекта. Версия — в скобках.

Примеры:

- `прогноз_итого_-_25-310_Реконструкция_НС_(Основная).xlsx`
- `прогноз_по_объектам_-_25-310_Реконструкция_НС_(Основная).pdf`
- `факт_детально_выделенные_-_25-310_Реконструкция_НС_(v2).xlsx`
- `сравнение_итого_-_25-310_Реконструкция_НС_(Основная_Факт_2025).pdf`
- `отчет_-_25-310_Реконструкция_НС_(Основная_Факт_2025).pdf`
- `справочник_группы_IIC.xlsx`
- `аудит_журнал_действий.xlsx`

Timestamp в имя не добавляется: повторное скачивание даёт копию в папке загрузок браузера.

Подписи кнопок выгрузки (не имя файла): [ACTION_LABELS](../../client/src/constants/actionLabels.ts) — «Выгрузить Excel», «Выгрузить PDF», «Выгрузить Excel (выделенное)», «Выгрузить Excel (сводная)».

## Что входит в имя

| Часть | Проектные вкладки | Прочие экраны |
|-------|-------------------|---------------|
| модуль | прогноз / факт / сравнение / отчет | справочник / аналитика / аудит / проекты |
| вкладка | итого / по_объектам / детально; для отчёта опускается | имя экрана: группы_IIC, нормы, журнал_действий, каталог |
| уточнение | выделенные, сводная — только если нужно отличить кнопку | обычно нет |
| проект | шифр и название из карточки проекта | опускаются вместе с `_ - _` |
| версия | имя выбранной версии; сравнение и отчёт — два имени через `_` | опускается |

«Версия» в скобках — это поле имени версии анализа, а не отдельная вкладка workspace. Вкладки проекта: прогнозирование, оценка факта, сравнение, отчёт. Модалки «Прогноз» и «Анализ версии» сохраняют имена вкладки-источника (`прогноз_итого`, `факт_анализ`).

## Правила очистки

- пробелы и символы Windows `\ / : * ? " < > |` заменяются на `_`, повторные `_` схлопываются;
- скобки оставляются только вокруг блока версии;
- дефис в шифре проекта (`25-310`) сохраняется;
- длина имени не больше 180 символов: при превышении обрезается название проекта, не модуль и не вкладка.

## Карта выгрузок

- Прогноз: итого / по объектам / детально (Excel и PDF), выделенные строки, сводная таблица, модалка «Прогноз».
- Факт: итого PDF, по объектам и детально (Excel и PDF), выделенные, сводная; модалка анализа — `факт_анализ`.
- Сравнение: PDF по секции, видимый Excel, детальный Excel, сводная.
- Отчёт производительности: `отчет_-_{код}_{название}_({план}_{факт}).pdf`.
- Каталог проектов, справочники, регистр норм, стоимость работ, факт-норма, динамика, журнал действий.

Подробности табличного экспорта прогноза: [forecast-export.md](forecast-export.md).
