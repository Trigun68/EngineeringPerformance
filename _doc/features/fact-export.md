# Экспорт оценки факта (PDF и Excel)

Дата обновления: 2026-09-05  
Реализация: `FactTableDocumentBuilder` → `ForecastTableRenderers`, `ProjectExportService`, `AnalyticsExportService`, `ProjectsPageController`

Кнопки оценки факта (модалка «Анализ версии», вкладки «Итого», «По объектам», «Детально») отдают **одну и ту же таблицу** в PDF и Excel. Меняется только формат файла. Подписи: **Выгрузить Excel**, **Выгрузить PDF**; на «Детально» — **Выгрузить Excel (выделенное)** и **Выгрузить Excel (сводная)**.

Заголовок модалки: `Анализ версии: {код} — {название} — {версия}`. Шапка колонок в окне — `#2C3E50`, шрифт `1rem`, длинные подписи переносятся. Карточка группы IIC = **own**-часы, **own**-физобъёмы/оборудование и трудоёмкость узла (как строка группы в гриде «Итого»), не свёртка потомков.

Визуальные PDF с графиками (`VisualReportService.ExportFact*`) с этих кнопок больше не вызываются.

## Оформление

Общая тёмно-синяя шапка (`TabularReportBanner`, `#2C3E50`, белый текст): название отчёта, `Проект: {код} — {название}`, `Версия анализа: …`, `Сформирован: dd.MM.yyyy HH:mm`.

Шапка таблицы — тот же `#2C3E50` / белый. В Excel шапка с переносом, ширины по содержимому (потолок 48). Цвета сценариев — пастель `#e3f2fd` / `#e8f5e9` / `#ffebee` на ячейках часов, тёмный текст; не заголовки и не насыщенные `#27AE60` / `#E74C3C`.

Порядок плановых часов везде: **Оптим. → Баз. → Песс.**

## Состав

| Экран | Колонки | Примечание |
|---|---|---|
| Анализ версии | Шифр, направление, факт ФО/ч, Оптим/Баз/Песс, факт/норм произв., Z, интерпретация | Первая строка «По проекту»; вложенные ФО/оборудование только в UI |
| Итого | Код, направление, ед. изм., ФО, факт ч, Оптим/Баз/Песс, факт/норм произв., Z, интерпретация | Дерево как на гриде. Follow-up: часы факта после rollup живут на L1; таблица пока печатает own `FactLaborHours` на листьях (вкладка «Отчет» уже показывает поддерево) |
| По объектам | Шифр, наименование, факт ч, Оптим/Баз/Песс, Z, интерпретация | Сначала топ-10 по **факт. часам** (блок скрыт, если объектов нет), затем все + ИТОГО |
| Детально | 26 колонок грида (привязка, TAG, комментарий, оценка, коэфф., **Факт.трудоёмк., ч**, три плана, **Факт производит.**, **Оценка Z**) | Все строки + ИТОГО часов; «Выгрузить Excel (выделенное)» — видимые колонки |
| Сводная | ФО → Оптим → Баз → Песс → Факт Тр. → Z | Четыре колонки итого: Оптим, Баз, Песс, Факт |

Эндпоинты: `GET /api/projects/{id}/versions/{vid}/export/fact-summary/{excel\|pdf}`, `fact-facility/…`, `fact-detail/…`, анализ — `…/analysis/excel` и `…/analysis/pdf`.

Имена файлов: [export-file-naming.md](export-file-naming.md) (`факт_анализ_-_{шифр}_{название}_({версия}).xlsx`).
