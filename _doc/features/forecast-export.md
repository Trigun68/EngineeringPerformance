# Экспорт прогноза (PDF и Excel)

Дата обновления: 2026-09-05  
Реализация: `ForecastTableDocumentBuilder`, `ForecastTableRenderers`, `ProjectExportService`, `ProjectsPageController`

Кнопки прогноза (модалка «Прогноз», вкладки «Итого», «По объектам», «Детально») отдают **одну и ту же таблицу** в PDF (QuestPDF) и Excel (ClosedXML). Меняется только формат файла. Подписи кнопок — из `ACTION_LABELS` / `ExportActionButton`: **Выгрузить Excel**, **Выгрузить PDF**; на «Детально» дополнительно **Выгрузить Excel (выделенное)** и **Выгрузить Excel (сводная)**.

Заголовок модалки: `Прогноз трудозатрат: {код} — {название} — {версия}`. Шапка колонок в окне — `#2C3E50`, шрифт `1rem`, длинные подписи переносятся. Карточка группы IIC = **own**-часы и **own**-физобъёмы/оборудование узла (как строка группы в гриде «Итого»), не свёртка потомков.

Визуальные PDF с графиками (`VisualReportService.ExportForecast*`) с этих кнопок больше не вызываются.

## Оформление

Общая тёмно-синяя шапка (`TabularReportBanner`): название отчёта, код и имя проекта, версия анализа, дата. Шапка таблицы: `#2C3E50`, белый текст; в Excel шапка с переносом (`WrapText`) и высотой 28 pt.

Заливки плановых часов — пастель грида / `ReportVisualTheme` (не столбики графиков), тёмный текст `#1B2A38`:

| Сценарий | Заливка |
|----------|---------|
| Оптимистичный | `#e3f2fd` |
| Базовый | `#e8f5e9` |
| Пессимистичный | `#ffebee` |

Строка **ИТОГО** — тёмно-синяя `#1E3A5F`, белый текст. Ширины колонок Excel: `RelativeWidth` + `AdjustToContents` (первые 200 строк, потолок 48).

## Состав

| Экран | Колонки | Примечание |
|---|---|---|
| Итого / модалка | Шифр, Направление, Факт ФО, Норма, **Оптимистический, ч**, **Базовый, ч**, Пессимистический, ч | Иерархия направлений как в гриде |
| По объектам | Шифр, наименование, **Оптимистический**, **Базовый**, Пессимистический | Сначала топ-10 по базовым часам, затем все объекты + ИТОГО |
| Детально | 22 колонки грида; последние три — Оптимистический, Базовый, Пессимистический | Все строки + ИТОГО часов; «Выгрузить Excel (выделенное)» — только видимые колонки |

Эндпоинты: `GET /api/projects/{id}/versions/{vid}/export/forecast-summary/{excel|pdf}`, `forecast-facility/{excel|pdf}`, `forecast-detail/{excel|pdf}`.

Имена файлов: [export-file-naming.md](export-file-naming.md) (`прогноз_итого_-_{шифр}_{название}_({версия}).xlsx`).
