# UAT Phase 4 — чеклист приёмки web-версии

**Обновлено:** 2026-06-08  
**Роли:** PM (Project Manager), Observer, Administrator

---

## Автоматическая проверка (агент / CI)

```bash
./scripts/uat-smoke.sh http://localhost:8081
cd client && npm run test:e2e
```

Playwright покрывает: login, навигацию, справочники, help, audit, права, вкладки проекта и сравнение.

---

## Общие проверки

- [ ] Вход JWT (логин/пароль) — также `e2e/migration-smoke.spec.ts`
- [ ] Вход SPNEGO (если включён на стенде)
- [ ] Выход и повторный вход
- [ ] Сообщение при истечении JWT (перелогин)

---

## PM — проекты и данные

- [ ] Список проектов, создание/редактирование
- [ ] Версии анализа: создать, копировать
- [ ] Вкладки данных: PPV, PLI, PEQ — просмотр и редактирование
- [ ] Импорт Excel: preview → confirm → rollback итерации
- [ ] Участники проекта

---

## PM — аналитика

- [ ] Оценка факта: дерево направлений, сводка
- [ ] Прогноз: дерево, редактирование плановых объёмов на листьях
- [ ] Сравнение версий: выбор A/B, фильтр «только различия»
- [ ] Экспорт Excel/PDF (оценка и прогноз)

---

## Observer

- [ ] Доступ только на чтение к разрешённым проектам
- [ ] Нет кнопок редактирования / импорта при AccessLevel=Read
- [ ] Нет доступа к `/settings/access-rights`

---

## Administrator

- [ ] Справочники: CRUD всех типов, export, unarchive
- [ ] Журнал действий `/audit`
- [ ] Матрица прав `/settings/access-rights`
- [ ] Пользователи (если доступно в web)

---

## Нефункциональные

- [ ] Грид 1000+ строк PPV — приемлемое время отклика
- [ ] Импорт файла ~10 MB — без таймаута
- [ ] Экспорт PDF/Excel — файл открывается в Office/viewer

---

## Критерий прохождения

Все пункты для роли PM и Admin — ✅; Observer — без нарушений read-only. Подпись заказчика → старт параллельной эксплуатации (MIG4-006).
