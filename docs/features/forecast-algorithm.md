# Алгоритм прогнозирования трудозатрат

Дата обновления: 2026-05-06  
Реализация: `ProjectForecastService.cs` → `BuildIicPlannedVolumeTree`

---

## Источники данных

| Источник | Описание |
|---|---|
| `ProjectPhysicalVolumes` | Фактические физические объёмы версии проекта (`IsAssessment = true`) |
| `AnalysisVersionSnapshots` | Снимок норм на дату создания версии проекта (уникален по `(VersionId, WorkDirectionId)`) |
| `IicWorkDirectionNorm.Performance` | Нормативная производительность (ч/ед) |
| `IicWorkDirectionNorm.StandardDeviation` | Стандартное отклонение производительности |

---

## Формулы (листовые направления ИИС)

### Базовый сценарий (20%)
```
Базовый = ФактФО × Performance
```

### Оптимистичный сценарий (15%)
```
Оптимистичный = ФактФО × max(0, Performance − 0.5 × StdDev)
```
Более высокая производительность → меньше трудозатрат.

### Пессимистичный сценарий (15%)
```
Пессимистичный = ФактФО × (Performance + 0.5 × StdDev)
```
Более низкая производительность → больше трудозатрат.

---

## Правила расчёта

- Если у направления нет нормы (`Performance = null` или `= 0`) — используются фактические трудозатраты (`ProjectLaborIntensities.PlannedHours`) как запасное значение базового сценария; оптимистичный и пессимистичный сценарии совпадают с базовым.
- Если `StdDev = 0` или отсутствует — все три сценария равны базовому.
- Для нелистовых узлов базовые часы = сумма базовых часов дочерних листьев.
- `ФактФО` агрегируется снизу вверх по дереву направлений ИИС с учётом коэффициентов `PhysicalVolume.Coefficient`.

## История изменений алгоритма

| Дата | Версия | Изменение |
|---|---|---|
| до 2026-05-06 | — | Лог-нормальное пространство: `base = ФО × exp(Estimate)`, сценарии через `exp(Estimate ± 0.5 × StdDev)` |
| **2026-05-06** | **текущий** | **Линейный алгоритм**: `base = ФО × Performance`, `opt/pes = ФО × (Performance ∓ 0.5 × StdDev)` |
